Changelog

Product/Service: context-stats

2.0.0

2026-10-12

New

  • Show the logged-in Claude account email next to the model with show_account=true, so you can tell which account a session runs under.

Fixed

  • Documentation no longer claims the removed cache-warm command kept the prompt cache alive.

Action needed

  • Remove any context-stats cache-warm calls from scripts: the command never reached the API and now exits with an error.

1.25.0

2026-09-02

New

  • A sixth “Pricing” context zone warns when a 1M-context session passes 150k tokens and each turn costs more; set the boundary with zone_pricing_max.
  • Every context-stats command now tells you once when the status line is installed but not wired into Claude Code, with the one-line fix.

1.24.2

2026-08-24

New

  • context-stats doctor checks the whole install chain and prints the fix; doctor --fix wires settings.json for you with a backup.

Fixed

  • The curl installer installs the current package instead of a stale alias.
  • A settings.json that is not valid UTF-8 is reported as a failed check instead of crashing doctor.

1.24.1

2026-08-24

Improved

  • The standalone script and the package now share one implementation, so both render the same status line.

Fixed

  • On Windows, the status line shows the project folder name instead of the full path.

1.24.0

2026-06-17

New

  • A pacman icon next to the zone label shows the context zone at a glance; hide it with show_pacman=false.
  • The current pull-request number appears in the status line by default.

Improved

  • Context usage, zone, and icon sit in one compact group, saving width on narrow terminals.

Older releases: https://github.com/luongnv89/context-stats/blob/HEAD/CHANGELOG.md
