context-stats puts free tokens, context zone, and model sharpness in your Claude Code status line. When a session ends, it tells you where the tokens and the money went.

  • Work done late in a full session gets redone in a fresh one, so you pay for it twice.

context-stats reads what Claude Code already reports, keeps a local history, and gives you three levels of answers.

Live

A status line with free tokens, a color-coded context zone, session cost, and an optional Model Intelligence score, refreshed on every turn.

Session

context-stats export writes a Markdown deep-dive: cache reuse, interaction timeline, and zone history for one session.

Report

context-stats report totals spend, cache hit ratio, and cost per project across every session, for any number of days.

How it works

Install the package:

pip install context-stats

Wire it into Claude Code:

context-stats doctor --fix

Restart Claude Code. The status line appears on the next turn.

FAQ

Is it free?

Yes. context-stats is MIT licensed and has zero runtime dependencies.

Does it send my data anywhere?

No. Session data stays in ~/.claude/statusline/, and reports read Claude Code's own logs in ~/.claude/projects/. The optional PR number is looked up through your local gh CLI.

What do I need to run it?

Python 3.10 or newer and Claude Code. The full multi-line layout needs Claude Code v2.1.153 or newer.

I installed it but no status line appears. What now?

Run context-stats doctor. It checks the entry points, a sandboxed render, the settings.json wiring, and the state directory, then prints the exact fix.

Can I hide parts of the status line?

Yes. Each element has a toggle in ~/.claude/statusline.conf, such as show_cost=false or show_delta=false, and accepts 18 named colors or any #rrggbb hex.

Does it slow Claude Code down?

Git commands run with a 5-second timeout, and the branch and PR number are cached between refreshes.
